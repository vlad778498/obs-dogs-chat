# Собаки чата — список исключений (ники, которые НЕ появятся на экране).
#
# Как пользоваться:
#   * Одна строка = один ник (регистр не важен: «StreamElements» = «streamelements»).
#   * Пустые строки и строки, начинающиеся с «#», игнорируются.
#   * Можно писать ник со знаком @ в начале («@BotName») — «@» игнорируется.
#   * Можно добавлять комментарии после ника: «SomeBot  # бот-модератор».
#   * Изменения применяются НА ЖИВО: файл перечитывается автоматически
#     каждые ~5 секунд, перезапускать сервис dogs-chat НЕ нужно.
#   * Удаление строки возвращает чатера обратно (если он снова напишет в чат).
#
# Примеры типовых кандидатов: чат-боты (StreamElements, Nightbot, Moobot,
# Fossibot, Wizey), счётчики, спам-фильтры.
