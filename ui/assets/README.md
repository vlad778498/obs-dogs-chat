# Ассеты (рисует автор)

Положите сюда свои PNG-файлы — интерфейс подхватит их автоматически,
эмодзи-заглушки исчезнут. Если файла нет — используется временная заглушка,
картинки НЕ обязательны для работы.

## Обязательный минимум (10 файлов)

| Файл                      | Что это                                                        |
|---------------------------|----------------------------------------------------------------|
| `kennel.png`              | Будка целиком (стены + крыша). Модераторы будут сидеть на крыше.|
| `dog-idle-right.png`      | Собака стоит/идёт, смотрит ВПРАВО (лицом по умолчанию)         |
| `dog-idle-left.png`       | Та же собака, смотрит ВЛЕВО                                    |
| `dog-walk-right.png`      | Шаг вперёд, смотрит вправо                                     |
| `dog-walk-left.png`       | Шаг вперёд, смотрит влево                                      |
| `mod-idle-right.png`      | Поза «на посту» для модератора на крыше, смотрит вправо        |
| `mod-idle-left.png`       | То же, смотрит влево                                           |
| `mod-walk-right.png`      | Ходьба модератора, вправо                                      |
| `mod-walk-left.png`       | Ходьба модератора, влево                                       |
| `frame-duration.txt`      | Длительность одного кадра в миллисекундах, например `250`      |

## Опционально (если рисуете больше поз)

| Файл                      | Что это                                          |
|---------------------------|--------------------------------------------------|
| `dog-run-right.png`, `dog-run-left.png`   | Бег (zoomies). Если есть — бег будет отдельным кадром. |
| `dog-sleep-right.png`, `dog-sleep-left.png` | Сон (для «засыпающих» собак).                    |

## Правила рисования (важно!)

1. **Прозрачный фон** — сохраняйте PNG с альфа-каналом.
2. **Все собаки — один холст одного размера**, например `200×200 px`.
   Позиция собаки внутри холста должна быть ОДИНАКОВОЙ во всех кадрах
   (иначе при смене кадра она будет "прыгать"). Проще всего рисовать
   все позы поверх одного фонового слоя-подложки и экспортировать вместе с ним.
3. **Ориентация**: рисуем так, чтобы собака смотрела ВПРАВО; левый вариант —
   просто отражённая копия (`-left` файлы). Если left-файлов нет, движок сам
   отзеркалит right-спрайт.
4. **Лапы на нижней кромке холста** — собаки стоят ровно на нижнем крае экрана.
5. **Будка**: её нижняя кромка = пол. Ширина будки на экране = ширина PNG.
6. **Масштаб задаётся в CSS** (переменные `--dog-size`, `--kennel-size`
   в `ui/dogs.css`) — не старайтесь рисовать "в размере экрана",
   дорисуйте с запасом разрешения (например 2x) и отмасштабируйте в OBS/CSS.
7. **Собаки наследуют цвет ника чатера** (как в Toca Boca): рисуйте собаку
   БЕЛЫМ/СВЕТЛО-СЕРЫМ силуэтом с тёмными деталями (глаза, нос, ошейник) —
   эти детали останутся, а белый окрас окрасится в цвет сообщения.
   Если хотите естественный окрас — напишите, отключим тонировку одной строкой.
8. **Модераторы** — та же собака, но с золотым венком/значком на шее
   (рисуется прямо на спрайте `mod-*.png`).

## frame-duration.txt

Это длительность ОДНОГО кадра анимации в мс. Примеры:
- `250` — спокойный шаг (по умолчанию);
- `120` — быстрый бег;
- если у вас только 2 кадра на походку, цикл = 2 × duration.

Формат файла: просто число, пустые строки и комментарии (`#...`) игнорируются.

## Как проверить без OBS

Откройте в браузере страницу сервера (`http://IP:8377`) — там есть кнопка
«🧪 Тест», которая эмулирует приход новых собак, уход, статус модератора
и перезагрузку ассетов после того, как вы добавили файлы на сервер.
