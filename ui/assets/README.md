# Ассеты (рисует автор) — система пород

Положите сюда свои PNG-файлы — интерфейс подхватит их автоматически
(кнопка «🔄 перезагрузить ассеты» на тестовой панели или перезагрузка
страницы). Пока файлов нет — показываются emoji-заглушки разных пород.

## Как устроены породы

Каждый чатер получает **породу детерминированно по нику** (один ник = одна
порода, не меняется между стримами). Порода = префикс имени файла.
Текущий список пород (можно расширять, см. ниже):

| Порода (префикс)  | Файлы                 | Заглушка |
|-------------------|-----------------------|----------|
| `labrador`        | `labrador-*.png`      | 🦮 |
| `shepherd`        | `shepherd-*.png`      | 🐕‍🦺 |
| `husky`           | `husky-*.png`         | 🐺 |
| `poodle`          | `poodle-*.png`        | 🩷🐩 |
| `corgi`           | `corgi-*.png`         | 🐶 |
| `beagle`          | `beagle-*.png`        | 🐶 |
| `bulldog`         | `bulldog-*.png`       | 🐕 |
| `dalmatian`       | `dalmatian-*.png`     | 🐕 |
| `greyhound`       | `greyhound-*.png`     | 🐕 |
| `pug`             | `pug-*.png`           | 🐶 |

## Схема имён файлов одной породы

Для каждой породы рисуем **2 кадра** (анимация «в пару кадров»),
смотреть будет вправо, влево — движок отзеркалит сам:

```
<порода>-idle-right.png    # кадр 1: стоит/сидит
<порода>-walk-right.png    # кадр 2: шаг
```

Минимальный полный набор для 10 пород — 20 файлов + будка.
Можно рисовать постепенно: порода без своих файлов берёт базовый спрайт
`dog-*`, а если и его нет — emoji той же породы.

## Базовые/общие файлы

| Файл                    | Что это |
|-------------------------|---------|
| `kennel.png`            | Будка целиком. Модераторы сидят на крыше. |
| `dog-idle-right.png`, `dog-walk-right.png` (+`-left`) | Универсальный «двортерьер» — запасной спрайт для пород без своих картинок |
| `mod-idle-right.png`, `mod-walk-right.png` (+`-left`) | Отдельный спрайт модератора на крыше (если не рисуется — используется спрайт породы shepherd/labrador/husky) |
| `frame-duration.txt`    | Длительность одного кадра в мс (сейчас `250`) |

Опционально для любой породы: `<порода>-run-right.png` (zoomies),
`<порода>-sleep-right.png`.

## Порядок поиска файла движком (для собаки породы X, поза P, сторона D)

1. `X-P-D.png` → 2. `X-P-other.png` (зеркало) → 3. `X-idle-...` →
4. `dog-P-D.png` (базовый) → 5. любой PNG, содержащий `X` в имени →
6. emoji-заглушка породы.

Поэтому можно называть файлы немного свободно
(`husky_walk_right.png`, `Husky-Idle-Right.png` — тоже будут найдены
на шаге 5, но лучше держаться канонической схемы).

## Правила рисования (важно!)

1. **Прозрачный фон** — PNG с альфа-каналом.
2. **Все кадры одной породы — один холст одного размера** (например 200×200 px),
   собака в кадре стоит в одном и том же месте — иначе при смене кадра она
   будет «прыгать». Разные породы могут иметь разный размер холста, но
   одинаковая высота на экране задаётся CSS (`--dog-size`).
3. **Ориентация**: рисуем собаку смотрящей ВПРАВО; `-left` файлы опциональны.
4. **Лапы на нижней кромке холста** — собаки стоят ровно на нижнем крае экрана.
5. **Будка**: нижняя кромка = пол; ширина на экране = ширина PNG.
6. **Масштаб задаётся в CSS** (`--dog-size`, `--kennel-w` в `ui/dogs.css`).
7. **Цвет**: собаки наследуют цвет ника чатера (правило `.tinted` в CSS;
   отключается классом `no-tint` у `#scene`). Если хотите естественный
   окрас — удалите правило тонировки из dogs.css.
8. **Расширение списка пород**: добавьте строку в объект `BREEDS`
   в начале секции «Породы собак» в `ui/dogs.js` и нарисуйте файлы
   с новым префиксом.
