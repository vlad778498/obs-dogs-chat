# 🐕 Собаки чата — OBS-плагин для Twitch

Выводит **активных чатеров** Twitch на экран стрима в виде собак.
Чатер считается активным, если писал сообщение **за последний час**.

## Как это работает

```
Twitch IRC (WebSocket, анонимно)  ->  учёт активности (Python)  ->  HTTP + SSE  ->  Browser Source в OBS
```

Каждый активный зритель получает карточку-«собаку»:
- порода закрепляется за ником детерминированно (один чатер = одна собака);
- «горячие» собаки (писали < 5 мин назад) светятся;
- полоска под ником показывает, сколько осталось до «остывания» (окно 1 час);
- когда время активности истекает — собака уходит с анимацией.

## Быстрый старт

### 1. Демо-режим (без Twitch, чтобы сразу настроить сцену)

```bash
python dogs_chat.py --demo
```

### 2. Боевой режим (реальный чат Twitch)

```bash
pip install websockets
python dogs_chat.py --channels канал1 канал2
```

Либо отредактируйте `config/settings.json`:

```json
{
  "channels": ["your_channel"],
  "active_window_seconds": 3600,
  "max_dogs": 60,
  "http_port": 8377
}
```

Подключение к чату — **анонимное** (justinfan), никаких токенов не нужно.
Читается только сам чат (PRIVMSG), без ботов-серверов.

### 3. Подключение в OBS

1. OBS → Источники (Sources) → **+** → **Браузер (Browser)**
2. URL: `http://localhost:8377`
3. Width: `1920`, Height: `1080` (или меньше — например 800×600 как панель у чата)
4. Можно снять галочку «Controlly cache» / увеличить Refresh browser cache, если нужно
5. Готово — собаки бегают на стриме 🐾

## Настройки (`config/settings.json`)

| Ключ | По умолчанию | Описание |
|---|---|---|
| `channels` | `["shroud"]` | Список каналов чата Twitch |
| `active_window_seconds` | `3600` | Окно активности («писал за последний час») |
| `refresh_ui_seconds` | `5` | Частота пуша обновлений в UI (SSE) |
| `max_dogs` | `60` | Максимум собак на экране (самые свежие) |
| `http_port` | `8377` | Порт локального HTTP-сервера |
| `nickname` | `""` | Ник для IRC; пусто = `justinfan<random>` |

## API

- `GET /` — страница для Browser Source
- `GET /api/dogs` — JSON: `{total_active, dogs: [{login,name,color,last_seen,messages,seconds_ago}]}`
- `GET /api/stream` — SSE-поток с теми же данными (используется UI)

## Идеи для развития

- Реальные картинки/спрайты собак вместо эмодзи (папка `data/` — под ассеты)
- Звуки «гав» при появлении новой собаки (через Web Audio в UI)
- Интеграция со StreamElements/EventSub для учёта подписок/донов (особая «порода»)
- docker-контейнер + автозапуск вместе с OBS (скрипт `.bat`/`.sh`)
